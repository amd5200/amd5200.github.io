# AeroShot AI - 投籃姿勢智能分析儀

AeroShot AI 是一個使用 TensorFlow.js 和 PoseNet 進行即時人體姿態偵測的網頁應用程式，專門設計來分析和評分籃球投籃動作。它提供即時回饋、視覺化 HUD 覆蓋層、評分儀表板和語音教練功能，幫助使用者改進投籃姿勢。

## 主要功能

- **即時姿態偵測**: 使用網路攝影機或本地影片檔案進行即時骨骼關鍵點偵測。
- **投籃動作狀態機**: 自動偵測投籃動作的四個階段：預備（Prepare）、釋放（Release）、隨手（Follow Through）和冷卻（Cooldown）。
- **多維度評分系統**:
  - 準備手肘角度（Set Point Elbow）: 評分起始姿勢中射手側手肘的彎曲程度（理想約 90°）。
  - 膝蓋驅動（Knee Drive）: 評分屈膝深度及伸展力度。
  - 出手延伸（Extension）: 評分投籃瞬間手臂伸展的完整度。
  - 軀幹平衡（Balance）: 評分預備與出手時軀幹前傾角度的變化幅度。
- **科幻風格 HUD 覆蓋層**:
  - 上方顯示 FPS、慣用手指示。
  - 中間顯示目前動作狀態（IDLE, PREPARE, RELEASE, HOLD POSE, EVALUATING）。
  - 下方顯示警告訊息（當偵測到身體未完全進入畫面時）。
- **儀表板分析**:
  - 環形圖顯示總體評分（0-100）。
  - 四個子項目評分儀表。
  - 即時儀表顯示手肘角度、膝蓋角度和軀幹傾角。
  - 語音教練開關（提供中文語音回饋）。
  - 即時文字回饋框，根據評分提供具體改進建議。
- **投籃歷史紀錄**:
  - 自動記錄每次投籃的評分與時間。
  - 支援匯出為 CSV 檔案。
  - 提供刪除單筆紀錄功能。
- **多種影像來源**:
  - 網路攝影機（預設）。
  - 本地 Demo 影片（需放置於同目錄）。
  - 上傳自訂影片檔案。

## 使用說明

1. **開啟應用程式**: 使用現代網頁瀏覽器（Chrome, Edge, Firefox 等）開啟 `shooter_train.html`。
2. **授予權限**: 首次使用時，瀏覽器會請求存取網路攝影機的權限，請點擊「允許」。
3. **選擇影像來源**:
   - 點擊「開啟相機」以使用網路攝影機。
   - 點擊「播放本機 Demo 影片」以使用預設的示範影片（請確認 `螢幕錄製 2026-07-15 221239.mp4` 檔案存在於同目錄）。
   - 點擊「上傳自訂影片」以選擇本地影片檔案。
4. **調整設定**（位於頁面上方）：
   - 慣用手: 選擇右手或左手投籃（系統會根據此設定分析對應側的身體部位）。
   - 門檻值: 調整姿態偵測的信心門檻（預設 0.80，數值越高要求越嚴格）。
5. **開始投籃**: 站在鏡頭前，進行完整的投籃動作（從準備、舉球、出手到隨手）。系統會自動偵測並評分。
6. **查看結果**:
   - HUD 中間會顯示目前狀態。
   - 右側儀表板會即時更新評分與子項目。
   - 底部歷史表會記錄每次投籃的結果。
7. **匯出紀錄**: 點擊「匯出 CSV 資料」以下載所有投籃紀錄。

## 技術細節

- **姿態估計模型**: 使用 TensorFlow.js 的 PoseNet MobileNetV1 版本，輸入解析度 320x240，輸出步幅 16。
- **關鍵點索遵循 COCO 格式**:
  - 肩膀: 左 5 / 右 6
  - 手肘: 左 7 / 右 8
  - 手腕: 左 9 / 右 10
  - 臀部: 左 11 / 右 12
  - 膝蓋: 左 13 / 右 14
  - 踝踝: 左 15 / 右 16
- **狀態機轉換條件**（根據手腕垂直位置、速度及角度變化）：
  - IDLE → PREPARE: 手肘 < 120°, 膝蓋 < 150°, 手腕在髖部上方 50px 內。
  - PREPARE → RELEASE: 手腕高於肩部 50px 內、平均手腕向上速度 > 3px/frame、手肘角度增加 > 5°。
  - RELEASE → FOLLOW_THROUGH: 手腕達到最高點（速度 < 4px/frame）、手肘角度 > 135°。
  - FOLLOW_THROUGH → COOLDOWN: 保持姿態 ≥ 15 框（約 500ms）。
  - COOLDOWN → IDLE: 冷卻時間 > 60 框（約 2秒）。
- **評分算法**（各項目佔比）：
  - 準備手肘角度: 35% （理想範圍 80-105°, 峰值於 92°）。
  - 膝蓋驅動: 20% （結合屈膝深度與伸展度）。
  - 出手延伸: 30% （理想手肘伸展角度 > 165°）。
  - 軀幹平衡: 15% （預備與出手時軀幹前傾角度差異）。
- **語音回饋**: 使用 Web Speech API 合成中文語音，提供即時教練建議。

## 系統需求

- 現代網頁瀏覽器（支援 `getUserMedia`, `requestAnimationFrame`, `SpeechSynthesis`）。
- 建議使用較新版本的 Chrome、Edge 或 Safari 以獲得最佳效能。
- 對於行動裝置，請確保授予攝影機存取權限，並注意效能可能較桌上型電腦為低。

## 注意事項

- 初次載入 PoseNet 模型時可能需要數秒時間，請耐心等待。
- 若使用 Demo 影片或上傳影片，請確認檔案格式為瀏覽器支援的 MP4/WebM 等。
- 若偵測不到完整身體，HUD 下方會顯示警告：「請將全身退入相機畫面中！」
- 評分門檻值可透過下拉選單調整，預設為 0.80（較嚴格），可根據環境光線或偵測品質降低以提高靈敏度。
