# 乾火訓練模擬器 — Dry Fire Trainer

基於 Web 瀏覽器、TensorFlow.js 與 PoseNet 姿態辨識技術的乾火射擊模擬器（Dry Fire Trainer）。
透過裝置相機即時捕捉射手肢體骨架、舉槍姿勢與手腕延伸瞄準線，提供靶紙命中判定、換彈手勢偵測、靶時（Par Time）與分段計時（Splits）功能。

## 📋 人體標記點修復說明 (Bug Fixes & Technical Details)

在先前版本中，使用者可能會遇到「**看不到人體標記點或骨架**」的問題，主要原因及修復細節如下：

### 1. 核心致命傷：PoseNet 視訊尺寸識別為 0
* **問題原因**：PoseNet 內部影像縮放函式 `U(t)` 讀取的是 HTML `<video>` 元素的 `.width` 與 `.height` 屬性，而非串流影像解析度的 `.videoWidth` 與 `.videoHeight`。由於 `<video>` 標籤未顯式指定 DOM 寬高，導致內部以 `[0, 0]` 進行運算，所有關節點座標被乘為 `(x: 0, y: 0)`，全數渲染至螢幕外（畫面右上邊界）。
* **修復方式**：在相機串流載入（`onloadedmetadata`）與偵測推論循環中，動態確保 `video.width = video.videoWidth` 與 `video.height = video.videoHeight`，讓 PoseNet 正確輸出以視訊實際解析度為基準的座標。

### 2. 推論循環中止問題 (ProcessFrame Loop Stall)
* **問題原因**：原 `processFrame` 在非同步推論進行中（`this.processing === true`）遇到動畫幀時直接 `return`，未排程下一次 `requestAnimationFrame`，導致推論僅執行 1 幀便永久停止。
* **修復方式**：重構為健全的 `requestAnimationFrame` 非同步循環，並搭配 `try...finally` 確保在推論結束後必定釋放推論鎖，達成穩定 60FPS 畫面更新與人體追蹤。

### 3. 視訊鏡像雙重反轉 (Double Flip)
* **問題原因**：前鏡頭（自拍模式）開啟時，CSS 已套用 `transform: scaleX(-1)` 翻轉視訊；但原程式在呼叫 `posenet.estimateSinglePose` 時設定了 `flipHorizontal: true`（翻轉一次），後續又在座標映射函式 `map(p)` 執行了 `(videoWidth - p.x)`（再次翻轉），導致負負得正，標記點與畫面中的人物左右顛倒。
* **修復方式**：將 PoseNet 內部 `flipHorizontal` 固定設為 `false`，保持原始視訊座標系；在渲染與計算時，統一依據 `camera.mirror` 進行精確自拍鏡像映射。

### 4. 畫面縮放與視訊裁切比例不一致 (fitBox)
* **問題原因**：視訊標籤採用 CSS `object-fit: cover`（等比例縮放填滿螢幕並裁切多餘邊界），但原座標縮放函式 `fitBox` 卻使用 `Math.min`（等同 contain 留黑邊），導致只要螢幕長寬比與相機解析度不同，標記點就會縮小位移。
* **修復方式**：修正 `fitBox` 為 `Math.max`，並精確計算置中位移偏移量（`sx`, `sy`），確保 Canvas 骨架與底層相機畫面達到 1:1 像素級精準對齊。

### 5. 骨架連線與標記點視覺強化
* **問題原因**：原版本僅連接軀幹 8 條線，無面部輪廓，且圓點僅 5px 無外框，在明亮或複雜環境下極難辨認。
* **修復方式**：
  * 補齊全身 15 條骨架連線（包含面容五官、雙肩手臂、軀幹、骨盆與雙腿雙腳）。
  * 關節標記採用高對比青色外光暈、實心標記圓點與白色立體中心。
  * 加入半透明中文文字標籤（如：`鼻子`、`左眼`、`右肩`等）。
  * **射擊專用腕部鎖定**：將射擊瞄準關鍵的「右腕」設為金色雙環標記，並在舉槍瞄準時繪製**手腕至準星的黃色虛線輔助瞄準線**。
  * **彈匣拔匣區條件顯示**：只有在腰部/右胯信心度足夠時才在腰際繪製拔匣感應區，避免空座標誤畫。

## 🚀 快速開始 (Getting Started)

> [!IMPORTANT]
> 現代瀏覽器（Chrome、Edge 等）因安全性限制，透過 `file://` 直接雙擊開啟 HTML 檔案時**會強制封鎖相機權限**。請務必使用本地 HTTP 伺服器開啟。

### 步驟 1：啟動本地伺服器
在專案根目錄（`c:\Users\User\dryfire-trainer`）開啟命令提示字元或 PowerShell：
```powershell
python -m http.server 8000
```

### 步驟 2：開啟瀏覽器
在瀏覽器網址列輸入：
[http://localhost:8000/dryfire.html](http://localhost:8000/dryfire.html)

### 步驟 3：授權相機權限
* 瀏覽器彈出相機存取詢問時，點選「允許」。
* 站在鏡頭前約 1.5 ~ 2.5 公尺處，即可即時看到自己的人體骨架標記點與瞄準準星。

## 🎯 操作指南與功能特色

| 按鈕 / 功能 | 說明 |
| :--- | :--- |
| **切換鏡頭** | 在前置自拍鏡頭與後置環境鏡頭之間切換（後置鏡頭自動取消鏡像反轉）。 |
| **切換槍種** | 切換 **手槍 (Pistol)** 與 **步槍 (Rifle)** 模式。<br>• 手槍：以右手腕與右肘延伸方向作為指向，彈匣容量 17 發。<br>• 步槍：結合雙手腕與雙肩中心軸線計算指向，彈匣容量 30 發。 |
| **校準** | 將準星對準靶心後點擊「校準」，系統會記錄偏移量，後續瞄準動作將以該基準點精準校正。 |
| **開始計時** | 開始訓練回合，進入射擊計時狀態（同時支援靶時 Par Time 警示）。 |
| **扣扳機** | 執行開槍判定；亦可使用**鍵盤空白鍵 (Space)** 或觸控點擊螢幕觸發。 |
| **換彈夾** | 重置彈藥數量；或使用**肢體手勢**：將手移至腰部右胯拔匣區再迅速舉起完成動態換彈。 |
| **模擬模式** | 當相機未開啟或無法使用時，系統會自動切換為滑鼠/手指觸控瞄準模式，方便離線調試。 |

## 🛠️ 技術架構

* **前端介面**：HTML5 Canvas + 原生 Vanilla CSS（玻璃擬態 HUD 戰術介面）
* **深度學習引擎**：TensorFlow.js (`@tensorflow/tfjs@3.11.0`)
* **姿態偵測模型**：PoseNet (`@tensorflow-models/posenet@2.2.2`, MobileNetV1 架構)
* **音效合成**：Web Audio API 原生振盪器合成（擊發、命中、脫靶、換彈金屬音效）
* **數據存儲**：IndexedDB 本地離線儲存射擊成績與分段計時紀錄
