# Target_shoot

靶紙射擊偵測與計分系統 (HTML + JavaScript)

## 使用說明

1. **開啟系統 (推薦使用本機伺服器)**：
   - 雙擊執行資料夾內的 `start_server.bat`，瀏覽器會自動開啟 `http://localhost:8000/Target_shoot.html`。
   - *(注意：現代瀏覽器如 Chrome/Edge 因資安限制，禁止在 file:// 協定直接開啟實體相機)*

2. **基本操作流程**：
   - 按下「開啟相機」或使用「載入圖片／影片檔案」載入測試媒體
   - 瞄準空白靶標（無彈孔）並調整視野大小
   - 按下「擷取基準背景」初始化自適應背景模型
   - （可選）使用「設定偵測區域」劃出只偵測靶標區域，避免背景雜訊
   - 調整偵測參數：變動差異門檻、最小/最大面積、背景適應率
   - 按下「開始彈孔偵測」開始偵測
   - 射擊時系統會自動標記彈孔、計分並語音播報「Hit [分數]」
   - 使用「匯出紀錄」下載 CSV，「儲存影像」下載 PNG

3. **特殊功能說明**：
   - **自適應背景模型**：新增背景適應率滑桿（預設 0.010），可自動緩慢更新背景模型以適應緩慢的光線變化，同時對快速變化（如彈孔）保持敏感
   - **手動目標選擇與追蹤**：按住滑鼠/手指拖曳選取目標，系統使用模板匹配持續追蹤移動中的目標（靶標晃動時特別有用）
   - **區域選擇 ROI**：支援滑鼠（桌機）和觸控（手機/平板）拖曳劃出偵測區域
   - **語音回饋**：偵測到新彈孔時使用 Web Speech API 播放「Hit [分數]」
   - **即時校正**：點擊畫面設定靶心位置，調整靶心半徑滑桿匹配實體靶標
   - **雙重去重機制**：15像素距離閾值 + 時間幀緩衝，避免同一彈孔重複計數
   - **環形計分**：10分環制，從中心向外每環遞減1分

4. **偵測參數調整指南**：
   - **變動差異門檻**：預設 35。若誤偵測過多（雜訊）增加此值；若漏偵測（彈孔太小）減少此值
   - **最小面積**：預設 10 像素。增加以過濾小噪點
   - **最大面積**：預設 500 像素。減少以過濾大面積移動物體
   - **背景適應率**：預設 0.010（**新增功能**）。此為關鍵改進！
     - **較小值 (0.001-0.005)**：背景更新緩慢，對振動異常穩定，適合固定靶標且有明顯震動的環境
     - **較大值 (0.01-0.05)**：背景更新較快，能適應緩慢光線變化，但可能對快速振動較敏感
     - **建議設定**：若發現靶紙被擊中後因震動造成誤偵測，請將此值調小（例如 0.003）；若環境光線緩慢變化且震動較小，可調大此值（例如 0.02）

5. **手機/平板使用說明**：
   - 區域選擇功能完全支援觸控：按住手指拖曳劃出矩形，離開手指確認
   - 手動目標選擇與追蹤同樣支援觸控操作
   - 所有滑桿與按鈕皆可正常觸控操作

## 技術說明

此系統使用純 HTML5/JavaScript 實現，核心偵測演算法為：
1. **自適應背景減法**：維持一個背景模型，並根據設定的適應率緩慢更新
2. **連通元件分析**：使用 4-連通 flood-fill (BFS) 識別顯著變異區域
3. **面積篩選**：根據最小/最大面積參數過濾噪點和大面積移動物體
4. **重複檢測抑制**：使用 15 像素歐幾里得距離閾值避免同一彈孔重複計數
5. **環形計分**：根據彈孔到靶心的距離計算得分（10 分制）

系統設計為完全在本機運行，不會上傳任何圖片或資料到外部伺服器，適合用於涉及敏感資料的訓練環境。

## 故障排除

### 相機無法開啟
- **症狀**：點擊「開啟相機」無反應或顯示錯誤
- **原因**：多為瀏覽器安全性限制或相機權限問題
- **解決**：
  1. 必須透過 `http://localhost:8000/` 存取（不可直接開啟 file:// 檔案）
  2. 點擊瀏覽器網址列左側的鎖頭圖示，確認「攝影機」權限設為「允許」
  3. 確認沒有其他程式佔用相機（Zoom、Teams、Discord 等）
  4. 嘗試重新整理頁面或重啟瀏覽器

### 誤偵測過多（假陽性）
- **症狀**：未射擊時持續標記紅點或計分增加
- **可能原因**：
  1. 差異門檻設定過低
  2. 背景適應率設定過高（對振動過於敏感）
  3. 環境光線不穩定或有強光直射
  4. 最小面積設定過小
- **解決建議**：
  1. 增加「變動差異門檻」值（例如從 35 增加到 45）
  2. **減少「背景適應率」值**（例如從 0.010 減少到 0.003）— 這是解決震動誤偵測的關鍵！
  3. 增加「最小面積」值（例如從 10 增加到 20）
  4. 確認穩定照明並避免背景有移動物體
  5. 重新擷取背景（確保瞄準空白靶標）

### 漏偵測過多（陰性）
- **症狀**：射擊後未標記彈孔或計分不增加
- **可能原因**：
  1. 差異門檻設定過高
  2. 最小/最大面積設定不當
  3. 彈孔與背景對比度不足
  4. 未在 ROI 內或未正確追蹤目標
- **解決建議**：
  1. 減少「變動差異門檻」值（例如從 35 減少到 25）
  2. 調整「最小面積」和「最大面積」值以匹配實際彈孔大小
  3. 確認有足夠的照明對比
  4. 使用「設定偵測區域」或「手動目標選擇」確認偵測區域正確

### 手機/平板相機無法使用
- **症狀**：在手機或平板瀏覽器上無法取得相機畫面
- **可能原因**：
  1. 瀏覽器未授予相機權限
  2. 使用了不安全的連接（非 HTTPS/localhost）
  3. 某些行動瀏覽器對 getUserMedia 有特殊限制
- **解決**：
  1. 確實透過本機伺服器存取（http://localhost:8000）
  2. 在行動瀏覽器中明確允許相機權限
  3. 嘗試使用 Chrome 或 Safari（通常對 getUserMedia 支援較好）
  4. 如需傳輸檔案測試，可使用「載入圖片／影片檔案」功能

## 需求與相容性

- **瀏覽器需求**：支援 `getUserMedia` 的現代瀏覽器（Chrome、Firefox、Edge、Safari）
- **作業系統**：Windows、macOS、Linux、Android、iOS
- **硬體需求**：任何支援網路攝影機的裝置
- **網路需求**：僅需本機網路（伺服器與瀏覽器間通訊），不需要上網

- 不會將任何圖片或視訊上傳到外部伺服器
- 不會收集或存儲任何個人資料
- 適合用於涉及敏感訓練資料的環境
