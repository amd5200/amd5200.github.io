# Target_shoot

靶紙射擊偵測與計分系統 (HTML + JavaScript)

## 使用說明

1. 將此資料夾內的 `Target_shoot.html` 用瀏覽器（Chrome、Edge 等）開啟。
2. 點擊頁面上的「**啟動偵測**」按鈕。
3. （可選）若靶紙不正好置中，可點擊「**校正靶位**」按鈕進入校正模式：
   - 點擊畫面上靶紙的中心點以設定靶心座標。
   - 可調整「**靶心半徑**」滑桿以匹配實際靶紙大小（預設 200px）。
   - 再次點擊「**校正靶位**」或「**取消校正**」結束校正。
4. 偵測門檻可即時調整（在偵測中或校正時皆可見控制面板）：
   - **暗色門檻 (0-255)**：像素的 R、G、B 全部小於此值才視為暗色點。數值越大，越容易偵測到較亮的彈孔；數值越小，則只偵測非常暗的點。依環境光線與彈孔顏色調整。
   - **最小面積 / 最大面積**：過濾太小的噪點或太大的區域，單位為像素²。可依彈孔大小調整。
   - **偵測方法**：
     - **連通元件 (Blob)**：偵測相連的暗色區域，**適用於圓形或不規則的彈孔**（只要是暗色斑點即可）。
     - **模板匹配 (Template)**：使用預設深色圓形模板，**較適合偵測近似圓形的彈孔**。
     - **深度學習模型 (COCO-SSD)**：使用 TensorFlow.js 的 coco-ssd 模型偵測物件，並過濾小物件當作彈孔。模型載入需網路連接，首次載入可能需數十秒。載入成功後即可使用。
5. **彈孔樣本積準（以框選方式）**（新功能）：
   - 點擊「**加入樣本**」按鈕進入樣本收集模式（按鈕變綠色）。
   - 在此模式下，使用者可在畫面上按下滑鼠左鍵並拖曳框選一個區域（可圈選彈孔周圍），放開滑鼠後系統會擷取該區域的圖像，轉為灰度並正規化後加入模板列表，參與後續的模板匹配偵測。
   - 點擊「**清除樣本**」按鈕可移除所有使用者加入的樣本（保留內建預設模板）。
   - 樣本數會顯示在按鈕下方。
6. 對準靶紙進行射擊，系統會即時偵測彈孔：
   - 偵測到的彈孔會以紅色半透明圓點標記在畫布上，並以 `#1`、`#2`、`#3`… 依偵測順序自動編號。
   - 彈孔對應的分數（根據距離靶心的環形計分）會顯示在該點旁邊。
   - 畫面下方的「**目前分數:**」會累加所有新偵測彈孔的分數，並同步顯示彈孔數、平均分數與明細表。
7. 偵測到彈孔後，畫面右下角會出現兩個按鈕：
   - **匯出紀錄**：將所有彈孔序號、座標、分數及時間戳匯出為 CSV 檔案。
   - **儲存影像**：將目前畫布（含偵測標記）儲存為 PNG 圖片。
8. 若要重新開始或停止偵測，點擊「**停止偵測**」按鈕，畫面會清除並將分數歸零，紀錄亦會被清除。

> **注意**：偵測演算法提供三種選項（模板匹配會同時使用內建模板與使用者框選的樣本），使用者可依彈孔形狀與環境切換。若仍有偵測不到的情形，請先調整「暗色門檻」與「最小/最大面積」，再嘗試切換偵測方法。DL 模型載入失敗時會顯示錯誤訊息，請檢查網路連線或瀏覽器主控台。
