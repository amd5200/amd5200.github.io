# Target_shoot

靶紙射擊偵測與計分系統 (HTML + JavaScript)

## 使用說明

1. **開啟系統 (推薦使用本機伺服器)**：
   - 雙擊執行資料夾內的 `start_server.bat`，瀏覽器會自動開啟 `http://localhost:8000/Target_shoot.html`。
   - *(注意：現代瀏覽器如 Chrome/Edge 因資安規定禁止在 `file://` 協定存取相機，請務必透過 `start_server.bat` 或本機伺服器開啟)*。
2. **啟動影像來源**：
   - **實體相機**：按下「**開啟相機**」按鈕，允許瀏覽器使用攝影機；此時彈孔偵測預設為關閉，方便先對準靶紙。
   - **影片/照片檔案**：可點擊紫色的「**載入圖片／影片檔案**」按鈕，直接選擇拍攝好的靶紙影片或圖片檔案進行測試。
3. **望遠與調整畫面**：
   - 使用「**相機望遠 Zoom**」滑桿放大畫面：若瀏覽器/相機支援硬體 zoom，會優先套用硬體 zoom；不支援時會以畫面裁切方式望遠預覽。
4. **擷取基準背景與開啟偵測**：
   - 點擊「**擷取基準背景**」按鈕記錄未射擊前的靶紙畫面。
   - 點擊「**開始彈孔偵測**」啟動偵測（若尚未擷取背景，系統會自動將當前畫面設為基準背景）。
5. **校正靶位**（可選）：
   - 若靶紙不正好置中，可點擊「**校正靶位**」按鈕進入校正模式：
     - 點擊畫面上靶紙的中心點以設定靶心座標。
     - 調整「**靶心半徑**」滑桿以匹配實際靶紙大小（預設 200px）。
     - 再次點擊「**校正靶位**」結束校正。
6. **偵測門檻調整**：
   - **變動差異門檻 (0-255)**：比較當前畫面與基準背景的 RGB 色彩變動程度。數值越低越靈敏，數值越高越能過濾微小光影起伏。
   - **最小面積 / 最大面積**：過濾太小的噪點或太大的區域（單位為像素²）。
7. **背景變動差異偵測原理**：
   - 本系統已改用「**背景色彩變動差異偵測 (Frame Differencing)**」，不再侷限於黑色彈孔。
   - 當子彈穿過靶紙形成破洞，該位置會露出與原靶紙背景不同的顏色（如黑框、紅心或後方背景），系統比對色彩變動即可精確判斷並標記彈孔位置。
8. **射擊與自動計分**：
   - 系統即時偵測新產生的彈孔，並在畫面上以紅色圓點、`#1`、`#2`、`#3` 順序標記與顯示發數得分。
   - 畫面下方同步累加總分、顯示彈孔數、平均分數與詳細射擊紀錄表。
9. **紀錄與影像匯出**：
   - **匯出紀錄**：將所有彈孔序號、座標、分數及時間戳匯出為 CSV 檔案。
   - **儲存影像**：將目前畫布（含靶心與彈孔標記）儲存為 PNG 圖片。
10. **停止與重置**：點擊「**關閉／停止**」按鈕可關閉相機、清除畫面並重置分數與背景。

  - 新增彈孔依序自動編號標記 (`#1`, `#2`...) 與即時分數統計明細表。

  - 新增「相機望遠 Zoom」滑桿與「開始/暫停彈孔偵測」控制。

  - **取消無效功能**：移除無法正常使用的「滑動視窗標準化互相關模板匹配」與「TensorFlow.js COCO-SSD 深度學習模型」，簡化介面與大幅提升執行效能。

    - 優化相機 `getUserMedia` 備選策略（自動自動調配後鏡頭與預設相機）及詳細錯誤提示。
