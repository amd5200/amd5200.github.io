# DVR AI 監視器影像分析系統 — 使用說明

## 專案結構

```
DVR_AI_Codex/
├── DVR_canvas_AI.html     ← 主程式（登入 + 三個監視器通道 + AI 偵測）
├── server.py              ← Flask 代理伺服器（必須先啟動）
├── download_model.py      ← 離線模型下載腳本
├── DVR_canvas.html        ← 舊版畫布（保留備份）
├── lib/
│   ├── tf.min.js          ← TensorFlow.js（離線版）
│   └── coco-ssd.js        ← COCO-SSD 物件偵測庫（離線版）
└── model/
    ├── model.json         ← COCO-SSD 模型定義
    ├── group1-shard1of5   ← 模型權重分片 1/5
    ├── group1-shard2of5   ← 模型權重分片 2/5
    ├── group1-shard3of5   ← 模型權重分片 3/5
    ├── group1-shard4of5   ← 模型權重分片 4/5
    └── group1-shard5of5   ← 模型權重分片 5/5
```

---

## 架構說明

```
瀏覽器  ──(HTTP)──▶  server.py (localhost:8000)
                       │
                       ├─ 提供 HTML / JS / 模型檔案
                       │
                       └─ /api/login        ──▶  DVR 登入
                          /api/snapshot?ch=X ──▶  DVR 截圖代理
```

> **為什麼需要代理伺服器？**  
> DVR 需要帳號密碼，且位於不同 Origin。  
> 瀏覽器的 CORS 安全機制禁止前端直接存取跨域影像並寫入 Canvas（AI 偵測需要讀取 Canvas 像素）。  
> 由 `server.py` 負責向 DVR 認證並代理截圖，前端從 `localhost` 取得圖片，即可正常讀取像素供 AI 偵測。

cd c:\Users\User\Documents\DVR_AI_Codex

## 啟動方式（每次使用前執行）

### 步驟 1：安裝相依套件（僅第一次需要）

```powershell
pip install flask requests
```

### 步驟 2：啟動 Flask 代理伺服器

```powershell
cd c:\Users\User\Documents\DVR_AI_Codex
python server.py
```

成功啟動後終端機顯示：
```
===================================================
  DVR AI 監視器代理伺服器
  請在瀏覽器開啟：http://localhost:8000
===================================================
```

### 步驟 3：開啟瀏覽器

```
http://localhost:8000
```

### 步驟 4：輸入 DVR 帳號密碼登入

頁面會顯示登入表單，輸入 DVR 的帳號與密碼後點擊「登入」。  
登入成功後自動顯示三個通道的即時截圖。

> ⚠️ **注意**：請勿用 `file://` 直接開啟 HTML，必須透過 `http://localhost:8000`。

### 停止伺服器

在終端機按 `Ctrl + C`。

## 功能說明

### 通道顯示
| 通道 | 來源（DVR 端） |
|------|----------------|
| 通道 01 | `?ch=1` |
| 通道 02 | `?ch=2` |
| 通道 03 | `?ch=3` |

### 截圖更新
- **📷 截圖**：手動抓取該通道最新畫面
- **🔄 全部刷新截圖**：同時更新三個通道
- **自動刷新頻率**：可選每 2 秒、5 秒、10 秒自動更新，或關閉

### AI 偵測
1. 等待頁面頂端顯示 **「✅ AI 模型已載入」**
2. 點擊 **「🔍 AI 偵測」** 或 **「🔍 全部 AI 偵測」**
3. 程式使用 COCO-SSD 模型對截圖進行偵測，並在畫面上繪製：
   - 紫色偵測框
   - 物件類別與信心分數標籤（例：`person 92%`）
4. 使用 **置信度** 滑桿調整顯示門檻，低於門檻的偵測結果不會顯示
5. 點擊 **「✕ 清除」** 可移除 AI 偵測結果，已設定的 AI 範圍會保留

### 手動 AI 偵測範圍
每個通道都可以手動框選 AI 偵測範圍：

1. 點擊該通道的 **「▣ 畫範圍」**
2. 在畫面上按住滑鼠並拖曳，放開後新增一個綠色 AI 範圍
3. 可在同一通道內畫多個範圍
4. 再次點擊 **「完成範圍」** 可結束畫框模式
5. 點擊 **「清範圍」** 可清除該通道所有手動畫框範圍

偵測規則：
- 若該通道沒有設定 AI 範圍，AI 會偵測整張畫面
- 若該通道已設定 AI 範圍，只顯示中心點落在範圍內的偵測結果
- 手動刷新或自動刷新截圖時，AI 範圍會保留，AI 偵測結果會重新計算

### AI 範圍物件數量清單
每個通道畫面下方會顯示 **「AI 範圍物件數量」** 清單。

清單會依照手動畫框分組統計目前偵測到的物件數量，例如：

```text
AI 範圍 1：car: 1，person: 2
AI 範圍 2：未偵測到物件
```

清單會在以下操作後即時更新：
- 執行單一通道或全部 AI 偵測
- 手動畫完新的 AI 範圍
- 清除 AI 偵測結果
- 清除 AI 範圍
- 重新截圖或自動刷新

### 語音提示
當已設定 AI 範圍，且範圍內偵測到指定物件時，瀏覽器會使用文字轉語音播放提示：

| 偵測類別 | 語音內容 |
|----------|----------|
| `car` | `五掐` |
| `person` | `五郎` |

語音提示有 3 秒冷卻時間，同一物件類別最多每 3 秒播放一次，避免自動刷新時連續播報。

> 注意：瀏覽器通常需要使用者先與頁面互動，才允許自動播放語音。登入、點擊偵測、或點擊畫範圍後即可正常觸發。

### 拍照功能
拍照功能預設為關閉，必須手動點擊 **「📸 開啟拍照功能」** 才會啟用。

啟用後，當 AI 偵測結果中出現以下任一物件時，系統會拍下目前通道畫面：
- `car`
- `person`

照片會透過 `server.py` 的 `/api/save-photo` API 儲存到專案目錄下的 `captures` 資料夾：

```text
C:\Users\User\Documents\DVR_AI_Codex\captures
```

檔名會依照序號與時間戳記自動產生：

```text
1_20260628_143012.jpg
2_20260628_143018.jpg
3_20260628_143025.jpg
```

檔名格式：

```text
序號_年月日_時分秒.jpg
```

如果資料夾中已經有舊檔名，例如 `1.jpg` 或 `2.jpg`，新的照片序號會接續既有最大序號往下排列。

若後端無法將照片儲存到 `captures` 目錄，前端會改在網頁上顯示該照片縮圖，並標示通道與失敗原因。

> 注意：新增或修改 `/api/save-photo` 後，需要重新啟動 `server.py`，前端拍照存檔功能才會生效。

### 模型載入邏輯
1. 優先載入本機 **離線模型**（`./model/model.json`）
2. 失敗時自動 fallback 至 **線上 CDN 模型**

## 常見問題

### 登入失敗
- 確認 DVR 帳號密碼正確
- 確認 `server.py` 已啟動且 DVR IP 可正常連線
- DVR 需支援 HTTP Basic Auth 或 Digest Auth

### 截圖顯示失敗（畫面黑色）
- DVR 截圖 URL 格式可能與預設不同，需在 `server.py` 的 `snapshot_candidates` 清單中加入正確的截圖路徑
- 常見截圖 URL 範例：`/snapshot?ch=1&type=0`、`/cgi-bin/snapshot.cgi?channel=1`

### 模型載入失敗
- 確認已執行 `python download_model.py`
- 確認使用 `http://localhost:8000` 開啟頁面

### 如何新增更多通道
複製 `DVR_canvas_AI.html` 中通道 03 的 HTML 區塊，修改 `ch=4` 並在 JavaScript 的 `CHANNELS` 陣列中加入 `4`。
