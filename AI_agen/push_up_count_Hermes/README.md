# 🏋️‍♂️ 智能伏地挺身計數器 (AI Push‑up Counter)

> 使用 **TensorFlow.js PoseNet** + **p5.js** 透過網頁攝像頭即時偵測人體關節，計算伏地挺身（Push‑up）次數並提供語音回報。  
> 介面採用深色玻璃磨砂設計，支援中英雙語切換，適合桌機與行動裝置。

---

## ✨ 功能特色

| 功能 | 說明 |
|------|------|
|即時姿勢偵測| 使用 PoseNet (MobileNetV1) 擷取 17 個關鍵點，畫出骨架與關節點。|
|智慧計數| 根據鼻子相對於肩膀的垂直位置以及手肘伸展角度（≥150° 視為伸直）判斷上升/下降階段，完成一次標準推舉即加 1。|
|語音回報| 每完成一次推舉，使用 Web Speech API 以目前語言（中文/英文）報出數字。|
|雙語介面| 介面內容（標題、按鈕、提示）可即時切換中文與英文。|
|視覺回饋| - 鼻子點顏色：紅色＝下降階段，綠色＝上升階段。<br>- 肩部水平線：黃色虛線作為參考。<br>- 手肘角度數值顯示於右側儀表板。|
|響應式佈局| 在寬度 ≥ 900px 時採用雙欄（左側畫布，右側資訊欄），較小螢幕則為單欄垂直堆疊。|
|零安裝| 僅需開啟 `push_up_count.html` 即可使用，無需任何本地端安裝或建置步驟。|

## 🚀 快速開始

1. **取得原始碼**  
   - 直接複製本倉庫，或下載 `push_up_count.html` 檔案。

2. **開啟網頁**  
   - 使用現代瀏覽器（Chrome、Edge、Safari、Firefox）開啟 `push_up_count.html`。  
   - 首次載入時瀏覽器會請求攝像頭權限，**請點擊「允許」**。

3. **使用方式**  
   - 面對攝像頭，確保頭部、肩膀、手肘、手腕全部進鏡。  
   - 待畫面左上角顯示「載入 PoseNet 模型…」消失後，即可開始做伏地挺身。  
   - 每完成一次正確的下降→上升動作，畫面上的數字會遞增並以語音報出。  
   - 右側儀表板會即時顯示目前狀態（UP/DOWN）與左右手肘角度。

4. **切換語言**  
   - 點擊右上角的 globe 圖示按鈕，可在中文與英文間切換。

## 🛠️ 如何自行修改或擴展

### 變更偵測模型
```js
// 在 setup() 中的 modelConfig 物件內修改
const modelConfig = {
  architecture: 'MobileNetV1', // 可試著改為 'ResNet50' (需額外模型)
  outputStride: 16,
  inputResolution: 512,
  multiplier: 0.75   // 0.5~1.0，數值越大越精確但較慢
};
```
> 注意：更換架構時請確認對應的模型已載入（例如 `posenet.load` 已支援的版本）。

### 調整計數門檻
- **直臂角度門檻**（目前 150°）：修改 `const STRAIGHT_ANGLE = 150;`  
- **鼻子‑肩膀垂直判斷**：目前直接比較 `noseY >= shoulderY`；可加入偏移量（例如 `noseY >= shoulderY + 10`）來減少誤觸。

### 新增其他運動計數
1. 在 `processPose()` 中加入對應關節的角度或位置運算。  
2. 在 `state` 狀態機中加入新的階段（例如蹲蹲的「下蹲」→「站起」）。  
3. 更新 UI（新增 metric‑card、角度顯示等）以及語音提示。

### 改善效能
- 把 `modelConfig.inputResolution` 調小（如 256）可顯著提升 FPS，但會降低關鍵點精度。  
- 若只需要特定關節（如肩膀、手肘、手腕），可在 `poseNet.estimateSinglePose` 後自行過濾不需要的點，減少後續運算量。

## 🐞 常見問題排除

| 症狀 | 可能原因 | 解決方案 |
|------|----------|----------|
| 只有攝像頭畫面，沒有骨架或關鍵點顯示 | 模型尚未載入完成或估計失敗 | 打開開發者控制台 (F12) 查看 Console 是否有錯誤訊息；確認網路可連線到 `cdn.jsdelivr.net`；若仍無法載入，可嘗試使用本地複製的 `posenet` 模型檔。 |
| 骨架顯示但計數不增加 | 關鍵點分數過低導致條件不被觸發 | 調整 `minConf`（建議 0.3~0.4），或在偵測畫面上顯示分數以確認實際值。 |
| 語音無聲音 | 瀏覽器封鎖自動播放或未授權語音合成 | 點擊頁面任意位置後再嘗試；或在設定中允許該網站使用語音合成。|
| 行動裝置畫面被切斷或只有上半部 | `video.hide()` 後仍有部分元素遮蔽 | 確認 `video.size(width, height)` 與 `createCanvas` 尺寸一致；可加入 `video.style('display', 'none')` 強制隱藏。 |
| 在某些瀏覽器上模型載入非常慢 | 第一次載入會從 CDN 下載數十 MB 模型 | 建議在開發階段使用較小的 `multiplier` (如 0.5) 或事先將模型下載至本地靜態資源。|
